# 09 — API Specification (v1)

The full schema is generated by FastAPI at `/api/v1/openapi.json`. Docs UI is enabled in dev/staging, and admin-only in production. This document is the design contract.

## Conventions
- **Base:** `https://<host>/api/v1`. JSON only. UTF-8.
- **Auth types:** `admin` (Bearer JWT, RBAC permission listed), `device` (kiosk device JWT, scoped to its current kiosk session), `public` (web booking page; rate limited + Turnstile/hCaptcha on the booking POST), `webhook` (signature verified).
- **Success envelope:** the resource itself (no wrapper). Lists: `{ "items": [...], "page": 1, "page_size": 20, "total": 123 }`.
- **Error envelope:**
```json
{ "error": { "code": "SLOT_UNAVAILABLE", "message": "That slot was just taken.", "details": {...}, "request_id": "…" } }
```
- **Idempotency:** `Idempotency-Key` header (UUID) is **required** on `POST /slot-holds`, `POST /bookings`, `POST /bookings/{id}/cancel|reschedule`, and `POST /event-enquiries`. Stored for 24 h.
- **Rate limits (Redis token bucket):** public 30 req/min/IP (booking POST 5/min/IP), device 120 req/min, admin 300 req/min, auth/login 5/min/IP + 10/hour/account.

## Error codes
`VALIDATION_ERROR` 422 · `UNAUTHENTICATED` 401 · `FORBIDDEN` 403 · `NOT_FOUND` 404 · `CONFLICT` 409 · `IDEMPOTENCY_MISMATCH` 409 · `SLOT_UNAVAILABLE` 409 · `CAPACITY_EXCEEDED` 409 · `HOLD_EXPIRED` 410 · `HOLD_NOT_ACTIVE` 409 · `OUTSIDE_BOOKING_WINDOW` 422 · `DATE_CLOSED` 422 · `GUEST_COUNT_INVALID` 422 · `INVALID_STATE_TRANSITION` 409 · `PAYMENT_VERIFICATION_FAILED` 400 · `RATE_LIMITED` 429 · `UPSTREAM_UNAVAILABLE` 503 · `INTERNAL` 500 (message sanitized).

## Endpoints

### Auth (admin)
| Method | Path | Notes |
|---|---|---|
| POST | /auth/login | `{email,password,totp?}` → access token + refresh cookie |
| POST | /auth/refresh | rotates refresh token. Reuse detection revokes the token family |
| POST | /auth/logout | revokes refresh token family |
| GET | /auth/me | current admin user, roles and permissions |

### Catalogue (public/device)
| GET | /packages?date=YYYY-MM-DD&guests=n | active packages. Includes `price_per_person` for that date's day type and `estimated_total` from the pricing service |
| GET | /packages/{id} | details + features |
| GET | /occasions | list + labels |
| GET | /business-info | name, address, hours, phone. **The only source the AI may quote** |

### Customers
| POST | /customers/validate | `{name?, phone?}` → normalized values + validation errors (no persistence) |
| POST | /customers | device/admin. Upsert by phone. Returns id |
| GET | /customers/{id} | admin (`customer.read`) |

### Pricing
| POST | /pricing/calculate | `{package_id, date, guest_count, occasion_code?, promo_code?}` → `{day_type, price_per_person, subtotal, discounts[], tax:{rate,amount,included}, charges[], total, currency:"INR", rules_applied[], quote_id, quote_expires_at}` |

### Availability
| GET | /availability/dates?package_id&guests&from&to | `[{date, status: OPEN|FULL|CLOSED, slots_available}]` |
| POST | /availability/slots | `{package_id, date, guest_count}` → `[{slot_key, start_at, end_at, duration_min, remaining, status}]`. Only slots that fit |

### Slot holds (device/public)
| POST | /slot-holds | `{slot_key, package_id, guest_count, session_id?}` → `{hold_id, expires_at, status}` (201). 409 SLOT_UNAVAILABLE |
| GET | /slot-holds/{id} | status + seconds remaining |
| POST | /slot-holds/{id}/extend | once, if allowed by config |
| DELETE | /slot-holds/{id} | release (idempotent) |

### Bookings
| POST | /bookings | `{hold_id, customer:{name, phone}, occasion_code, occasion_details?, consents:{whatsapp:bool}, quote_id}` → `{id, reference, status:"CONFIRMED", payment_status, pricing_snapshot, start_at, …}` (201). Re-prices server-side. If the price changed from the quote, returns 409 `PRICE_CHANGED` with the new quote (no silent change) |
| GET | /bookings/{id} | device (own session's only) / admin |
| POST | /bookings/{id}/cancel | admin (`booking.cancel`), or a customer via signed link (R1.1) |
| POST | /bookings/{id}/reschedule | `{new_hold_id}` atomic: convert new hold, release old slots |

### Event enquiries
| POST | /event-enquiries | `{customer, occasion_code, guest_count, preferred_date?, details}` → `{reference}`. Notifies staff |

### Kiosk (device)
| POST | /kiosk/register | `{pairing_code, name}` → device credentials (one-time code issued in admin) |
| POST | /kiosk/token | `{device_id, secret}` → device JWT |
| POST | /kiosk/heartbeat | `{app_version, camera_ok, mic_ok, speaker_ok, voice_ok}` → `{config}` |
| GET | /kiosk/status | device's own status/config |
| POST | /kiosk/session/start | → `{session_id}` |
| POST | /kiosk/session/end | `{session_id, reason}`. Releases holds |
| POST | /kiosk/staff-assist | raises an alert |

### Webhooks
| POST | /webhooks/whatsapp | GET verify challenge + POST status. `X-Hub-Signature-256` HMAC verified |
| POST | /webhooks/razorpay | `X-Razorpay-Signature` HMAC verified; dedupe by event id |

### Admin (`/admin/...`, all require admin JWT + permission)
Dashboard (`GET /admin/dashboard?from&to`), packages CRUD, pricing-rules CRUD + `POST /admin/pricing/preview`, business-hours, schedule-exceptions CRUD, resources, slot regeneration, bookings (search with filters + pagination, create manual (uses the same hold→book path), update status, cancel, reschedule), customers (search, history, consents, `POST /admin/customers/{id}/anonymize`), enquiries, kiosks (list, issue pairing code, disable, config), AI config (provider, model, voice, greeting, limits, spend caps), usage reports, audit log viewer, system settings.

**Implemented in Sprint 1:** `/admin/packages` (CRUD + soft delete), `/admin/occasions`, `/admin/pricing-rules` (CRUD; DELETE deactivates), `/admin/pricing/preview`, `/admin/settings/{pricing|booking}`, `/admin/business-info`, `/admin/schedule/hours`, `/admin/schedule/exceptions`, `/admin/resources`, `/admin/users`. Public: `/packages`, `/packages/{id}`, `/occasions`, `/business-info`, `/pricing/calculate`.

**Implemented in Sprint 2 (booking engine):**
| Method | Path | Auth / headers | Notes |
|---|---|---|---|
| POST | /availability/slots | public | `{package_id, date, guest_count}` → `{date, status: OPEN/FULL/CLOSED, closed_reason, slots:[{start_time, end_time, start_at, end_at, duration_min, remaining}]}` |
| GET | /availability/dates | public | `?package_id&guests&from&to` (≤ 31 days, clipped to the booking window) |
| POST | /slot-holds | public, `Idempotency-Key` | `{package_id, date, start_time:"HH:MM", guest_count}` → 201 `{hold_id, hold_token, expires_at, start/end…}`. 409 SLOT_UNAVAILABLE, 422 DATE_CLOSED / ENQUIRY_REQUIRED / GUEST_COUNT_INVALID |
| GET | /slot-holds/{id} | `X-Hold-Token` | status, seconds_remaining |
| POST | /slot-holds/{id}/extend | `X-Hold-Token` | once per hold |
| DELETE | /slot-holds/{id} | `X-Hold-Token` | idempotent release |
| POST | /bookings | public, `Idempotency-Key` | `{hold_id, hold_token, customer:{name, phone}, occasion_code, occasion_details, consents:{whatsapp}, quote_id?, notes?}` → 201 booking with `booking_token`. 410 HOLD_EXPIRED, 409 HOLD_NOT_ACTIVE / PRICE_CHANGED / SLOT_UNAVAILABLE, 422 ENQUIRY_REQUIRED |
| GET | /bookings/{id} | `X-Booking-Token` | customer self-view (phone masked) |
| POST | /event-enquiries | public, `Idempotency-Key` | → 201 `{reference: ENQ-…}` |
| GET | /admin/bookings | `booking.read` | filters `from,to,status[],phone,reference`, paginated |
| GET | /admin/bookings/{id} | `booking.read` | full detail + status history |
| POST | /admin/slot-holds, /admin/bookings | `booking.write`, `Idempotency-Key` | staff channel, same engine |
| POST | /admin/bookings/{id}/cancel | `booking.write` | frees capacity |
| POST | /admin/bookings/{id}/reschedule | `booking.write` | `{hold_id, hold_token, reason}`; same package and group size; re-prices for the new date and records old/new totals in history |
| POST | /admin/bookings/{id}/status | `booking.write` | COMPLETED / NO_SHOW, only after the start time |
| GET/PATCH | /admin/enquiries[/{id}] | `enquiry.manage` | status pipeline, staff notes |

Rate limit for booking writes: 10/min/IP (public). Kiosk device authentication (KIOSK-01) will give the kiosk its own channel and limits.

**Implemented in Sprint 3 (kiosk):**
| Method | Path | Auth | Notes |
|---|---|---|---|
| POST | /admin/kiosks | `kiosk.manage` | `{name}` → device + one-time pairing code `XXXX-XXXX` (15 min) |
| POST | /admin/kiosks/{id}/pairing-code | `kiosk.manage` | re-pair (rotates the device secret when redeemed) |
| GET/PATCH | /admin/kiosks[/{id}] | `kiosk.manage` | status (ACTIVE/DISABLED), config, online/heartbeat/version |
| POST | /kiosk/register | public, rate limited | `{pairing_code}` → `{device_id, device_secret}` |
| POST | /kiosk/token | public, rate limited | `{device_id, device_secret}` → 1-hour device JWT (`typ=device`) |
| POST | /kiosk/heartbeat | device JWT | `{app_version, camera_ok…}` → kiosk config |
| WS | /ws/kiosk | device JWT in first frame | intents → full state snapshots (protocol in `app/websocket/kiosk_ws.py`) |

Kiosk intents: `start, continue, set_name, set_phone, confirm_phone, set_guests, set_occasion, submit_enquiry, select_package, select_date, select_slot, set_consent, extend_hold, confirm_booking, finish, back, edit{field}, staff_assist, staff_resume, cancel, reset, set_language`. The server rejects intents that aren't allowed in the current state (`INVALID_STATE_TRANSITION`).

Health: `GET /healthz` (liveness, no deps), `GET /readyz` (DB, Redis, migrations at head).

## WebSocket contracts

### `/ws/kiosk` (device JWT; JSON messages `{type, id, ts, payload}`)
**Client → server (intents):**
`session.start`, `session.end`, `presence.update {present, faces}`, `intent.set_name {name}`, `intent.set_phone {phone}`, `intent.confirm_field {field}`, `intent.set_guests {n}`, `intent.set_occasion {code, details?}`, `intent.select_package {package_id}`, `intent.select_date {date}`, `intent.select_slot {slot_key}`, `intent.extend_hold`, `intent.confirm_booking {whatsapp_consent}`, `intent.edit_field {field}`, `intent.staff_assist`, `intent.cancel`, `ui.language {lang}`, `device.health {...}`.

**Server → client:**
`state.updated {state, data, allowed_intents[], version}` (canonical, full snapshot, monotonic `version`), `ui.show {component, props}` (e.g. package comparison), `hold.updated {hold_id, expires_at}`, `booking.confirmed {reference, …}`, `error {code, message, recoverable}`, `voice.status {listening|thinking|speaking|offline}`, `caption {role, text, final}`, `session.reset`.

Ordering: the server rejects intents whose `based_on_version` is older than the current version for fields that changed (prevents stale double-taps).

### `/ws/voice` (device JWT, bound to `session_id`)
Binary frames: PCM16 mono little-endian, client→server 16 kHz (gateway resamples per provider), server→client 24 kHz.
JSON control: `audio.interrupt` (server→client: flush playback), `audio.mute`/`unmute` (client→server), `voice.ready`, `voice.error {code}`.
